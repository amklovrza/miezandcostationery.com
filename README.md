This is the project Miez & co. stationery website. The version is Miez&co.v.1.
./main/cart_ui.py → contains the interface for purchases by the customer.
./main/main.py → contains the home page of the website, the navigation, and other code related to the appearance of the home.
./main/requirements.txt → text file that contains the packages needed to run the website.
./main/site_chrome.py → contains the config of the website, the header and footer, etc.
|
|_ /pages → contains all pages: collections, customer account, contact and FAQ, and products. 
|_ /assets → contains the collections and products' images, the logo, and the header image for all pages.
|_ /.streamlit → contains the setup of the colors of the website.
